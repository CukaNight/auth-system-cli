# 🔐 Система регистрации и входа

Консольное приложение на Python для регистрации и аутентификации пользователей с сохранением данных в JSON.

## Возможности

- 📝 Регистрация новых пользователей
- 🔑 Вход с проверкой логина и пароля
- 🛡️ Проверка, что логин не занят
- 🔒 Подтверждение пароля
- 💾 Сохранение пользователей в `users.json`
- 🚫 Защита от ввода букв в меню

## Как запустить

```bash
python auth_system.py
